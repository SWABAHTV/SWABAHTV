## 🚀 Featured Projects

### 🚢 [Titanic Survival Prediction](https://github.com/SWABAHTV/Titanic-Survival-Prediction)
Binary classification predicting passenger survival using Logistic Regression and Random Forest.
- **Best model:** Random Forest — 81.6% accuracy (vs. 79.9% for Logistic Regression)
- **Key insight:** Sex was the strongest predictor of survival
- **Stack:** pandas, scikit-learn, seaborn

### 🏠 [California House Price Prediction](https://github.com/SWABAHTV/California-House-Price-Prediction)
Regression project predicting median house values using Linear Regression and Random Forest.
- **Best model:** Random Forest — R² of 0.775 (vs. 0.640 for Linear Regression)
- **Key insight:** Median income was the strongest driver of house value
- **Stack:** pandas, scikit-learn, seaborn

### 💳 [Credit Risk Analysis & Default Prediction](https://github.com/SWABAHTV/credit_risk_analysis)
